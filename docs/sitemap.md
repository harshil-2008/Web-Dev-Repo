# Sitemap for StudentHub

A sitemap shows all the pages in a website and how they connect.

```text
Home Page (index.html)
 |
 |-- About Us (about.html)
 |-- Register (register.html)
 |-- Login (login.html)
 |-- Dashboard (dashboard.html)
 |-- Events (events.html)
 |-- User Profile (profile.html)
 |-- Contact Us (contact.html)
 |-- Admin Panel (admin.html)
 |-- FAQ (faq.html)
 |-- Feedback (feedback.html)
```

## How users navigate:
1. Everyone starts at the Home Page.
2. From the Home Page, you can click on the navigation menu to go to any other page.
3. If you want to see your personal info, you have to go to the Login page first, and then it takes you to the Dashboard.
