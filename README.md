# My Web Dev Project - StudentHub

Welcome to my StudentHub project! This is my semester-long project for my Web Development class.

## Project Folders
- `StudentHub/`
  - `css/` (where I put my CSS files)
  - `images/` (where I will put pictures later)
  - `index.html` (Home page)
  - `about.html`, `login.html`, etc. (Other pages)
- `docs/` (where I keep my planning documents like sitemaps and wireframes)
- `README.md` (This file!)

## What I Did in Practical 1
I planned out my website! I thought about what pages a student portal would need, like a login page, dashboard, and events page. 
Then I created a sitemap to show how the pages link together, and a wireframe to show what a basic page looks like. I also set up this GitHub repository.

## What I Did in Practical 2
I made the basic HTML skeletons for 11 pages! I learned about "Semantic HTML", which means using tags like `<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, and `<footer>` instead of just using `<div>` everywhere.
This makes the website better for accessibility (like screen readers). I also added breadcrumb links to help users know where they are.
